Referência

Glossário
de TI.

Termos que aparecem nas minhas aulas e nos posts do blog, explicados sem enrolação.

API

Sigla de "Application Programming Interface". É um jeito padronizado de um sistema conversar com outro — como um garçom que leva seu pedido até a cozinha e traz a resposta de volta.

Framework

Um conjunto de ferramentas e regras prontas que ajudam a construir um programa mais rápido, seguindo um padrão já definido — em vez de começar tudo do zero.

Banco de dados

Onde um sistema guarda informação de forma organizada, pra poder buscar, alterar e apagar depois. Exemplos: PostgreSQL, MySQL.

Front-end

A parte de um sistema que a pessoa vê e interage — telas, botões, formulários.

Back-end

A parte de um sistema que roda "por trás", sem a pessoa ver — processa regras, acessa banco de dados, responde pedidos do front-end.

Repositório (Git)

Uma pasta de projeto com histórico de todas as mudanças já feitas nela, guardada geralmente no GitHub.

Deploy

O ato de colocar um sistema no ar, disponível pra outras pessoas acessarem.

Bug

Um erro no código que faz o programa se comportar de um jeito que não devia.

Lógica de programação

A capacidade de organizar o raciocínio em passos claros pra resolver um problema — a base de tudo antes de aprender qualquer linguagem.

Clean Architecture

Um jeito de organizar um sistema em camadas separadas (regras de negócio, banco de dados, interface), pra facilitar manutenção e troca de tecnologia no futuro.

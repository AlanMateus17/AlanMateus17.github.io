{% comment %} scripts.html — carrega, em ORDEM, todo o JavaScript usado em mais de uma página do site. Incluído uma única vez, no fim do de _layouts/default.html (e, por consequência, em toda página que usa esse layout — inclusive as páginas de portfólio, que agora estendem o default em vez de duplicar tudo). A ordem importa: cada arquivo pode depender do que veio antes dele. Todos usam "defer", que significa "baixa em paralelo com a página, mas só executa depois que o HTML inteiro terminou de ser lido" — por isso é seguro carregar tudo aqui em cima do rodapé, mesmo que o elemento que um script procura só apareça mais abaixo no HTML. Scripts de UMA página só (ex: pages/curriculo.js) NÃO ficam aqui — eles são carregados só na própria página, no fim do arquivo dela. {% endcomment %} {% comment %} 1) Ponte com o _config.yml — precisa vir primeiro {% endcomment %} {% comment %} 2) Módulos "core": infraestrutura reaproveitada por várias features {% endcomment %} {% comment %} 3) Features: cada uma só age se encontrar seu elemento na página atual {% endcomment %} {% comment %} 4) Compartilhar página como Story: depende de bibliotecas externas (html2canvas) e da biblioteca local de QR code — por isso vêm antes. {% endcomment %}

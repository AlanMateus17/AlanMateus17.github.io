{% comment %} === scripts.html === Ponto único de carregamento do JS do site inteiro (incluído por `_layouts/default.html`, então roda em toda página). ORDEM IMPORTA: cada arquivo abaixo pode depender do que veio antes dele (ex.: `core/counter-api.js` usa `AMSite.config`, definido em `site-config.js`). Todos usam `defer`, então: - baixam em paralelo, sem travar a renderização da página; - executam só depois que o HTML inteiro terminou de carregar; - executam NESTA ORDEM (a ordem do documento), nunca fora de ordem. Cada arquivo de `features/` se auto-verifica ("o elemento que eu preciso existe nesta página?") antes de fazer qualquer coisa — por isso é seguro carregar todos eles em toda página, mesmo que a feature só apareça em algumas: nas páginas onde não se aplica, o arquivo simplesmente não faz nada. Os scripts de UMA página só (`pages/curriculo.js`, `pages/citacao.js`, `pages/trilha.js`) NÃO estão aqui — são carregados individualmente só na própria página, pra não pesar o carregamento das demais. {% endcomment %}
